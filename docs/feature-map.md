# Feature map

This map lists each user-visible feature of the desktop app by the name that
the English UI shows. A request, a bug report or a QA flow can name a feature
("the downloads window", "Force reload", "the thing in the left bar"). Use the
map to find the place in the UI and the source that owns it.

How to read an entry:

- **Visible name** is the English text from `src/i18n/en.i18n.json`, without
  the `&` access-key markers. `{{- appName}}` shows as "Rocket.Chat".
- **Key** is the i18n key. Search the source for the key to find each place
  that shows the text. A dash means that the text comes from somewhere else,
  such as the server, the OS or a workspace name.
- **Where and how to open** names the surface and the user action.
- **Source** is the file that owns the feature. Paths start at the repository
  root.
- **Platform** names a limit that the code applies. "All" means no limit.

The map lists what the source shows, not what it should show. When a label is
ambiguous, the entry says so. The spec `scripts/featureMap.spec.ts` fails when
a Settings control or a menu item exists in the source but its key is not in
the Key column of this map. When it fails, add a row for the label that the
error names. It also fails when a key in the map is not in
`src/i18n/en.i18n.json`.

The spec reads the Settings sections, the feature components they render and
the components those import from the same folder. It reads `label` and
`placeholder` props, the text of a `Button` or a `FieldLabel`, and the
`settings.options.*.title` keys. It reads the menus in `menuBar.ts`,
`trayIcon.ts`, `popupMenu.ts` and `rootWindow.ts`. The other rows (windows,
dialogs, notifications, toolbars) have no check that keeps them current.

## Root window

The root window holds the workspaces. Its chrome changes with the
**Workspace switcher** setting (Settings > Appearance, or View > Tabs, Sidebar
or Titlebar). `src/ui/components/Shell/index.tsx` picks the layout.

| Layout   | What the user sees                                                                                                      | Source                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Tabs     | A horizontal tab bar at the top, with one tab per workspace. The titlebar controls sit at the right end of the tab bar. | `src/ui/components/TabBar/index.tsx`                                                |
| Sidebar  | A vertical bar of workspace tabs at the left ("the left bar"). The Application menu button sits at its bottom.          | `src/ui/components/TabBar/index.tsx` (vertical)                                     |
| Titlebar | No tab bar. A thin top bar shows the active workspace name, which opens the workspace popup menu.                       | `src/ui/components/TopBar/index.tsx`, `src/ui/components/TopBar/ServerSwitcher.tsx` |
